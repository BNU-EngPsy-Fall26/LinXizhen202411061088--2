# 飞行训练舱

通过 GitHub Pages 或直接打开根目录的 `index.html` 运行。使用电脑、鼠标和键盘。无第三方运行依赖。

## W5 四表巡检

四档常态角速度为 8、16、32、64°/秒。指针在两次折返之间匀速移动，初始位置、初始方向和折返点随机。折返点在距离正常中点 25°–41° 的范围内，越限时指针用 1.4 秒平滑移向最近的红区，短暂停留后用 1.4 秒返回，再从原位置继续摆动。事件轨迹的速度上限约为 63°/秒。四根指针始终可见。鼠标位置作为查看位置的操作性代理，停留至少 0.1 秒计一次访问。鼠标位置不能等同于真实眼动。任何表进入红区时按空格，程序自动归入当前越限。

对齐与错开各一轮，顺序随机。对齐时四表正常中点一致，错开时分别旋转 −35°、−18°、18°、35°。参照刻线、红区和指针共同旋转。每轮 16 个连续事件窗口，每窗一件事件，四块表各 4 件，起始时刻随机，越限互不重叠。每位被试两轮使用相同的角速度—位置映射。计算被试内的检出率差，并描述命中反应时。汇总只纳入本版 W5。

改进依据是显示兼容性与参照一致性。当四块表的正常方向一致时，参与者可以用同一空间参照在仪表之间转移注意；参照错开时需要额外完成方向转换。因此预测对齐布局的越限检出率更高、命中反应更快。

基于 Senders（1964），https://doi.org/10.1109/THFE.1964.231647 。原研究操纵信号带宽，本版操纵常态角速度。与原研究对照的是变化快慢和查看频率的关系。鼠标访问与眼动注视的操作定义不同，且本版将越限事件在四档间均衡安排。

## W7 双表盘

相同的 12 对角度用于起点对齐和起点错开两个条件，共 24 题，混排。起点方向覆盖四个象限方向，错开幅度为 90°，顺、逆方向均可能出现。参与者估左角为右角的百分之几。每题绝对误差以百分点计，先按参与者求各条件均值，再求错开减对齐的被试内差值。反应时作为描述性指标。

改进依据是共同参照有助于视觉比例比较。起点对齐时，两个角度可以从同一基准直接比较；起点错开时，参与者需要先完成心理旋转或参照转换。因此预测起点错开会增加角度比例估计的绝对误差。

改编自 Cleveland 与 McGill（1984）的角度比例估计任务，https://doi.org/10.1080/01621459.1984.10478080 。他们比较图形编码，本任务比较双表盘的起点对齐。可以讨论两者共同的视觉比例估计任务，条件效应有各自的比较对象。

## 预测草案

- W5：指针常态角速度越高，主动查看频率越高。
- W5 改进：对齐条件的越限检出率较高。
- W7：起点对齐条件的估计绝对误差更小。

## 数据与结果

汇总包含 12 组匿名记录。四表巡检与双表盘均按同一分析流程计算条件均值和被试内差值。

- 四表巡检的 8、16、32、64°/秒平均鼠标访问率依次为 2.81、3.92、5.61、6.67 次/分。
- 参照对齐条件的越限检出率为 85.94%，参照错开条件为 75.00%，相差 10.94 个百分点。命中反应时分别为 508 ms 和 592 ms。
- 双表盘起点对齐条件的平均绝对误差为 6.49 个百分点，起点错开条件为 8.83 个百分点，错开增加 2.34 个百分点。

四表巡检的总体趋势与 Senders（1964）关于变化更快的仪表需要更高采样频率的方向一致。本实验使用鼠标代理查看位置，测量方式与原研究不同，因此只比较趋势。新增条件显示参照方向对齐时检出率更高、反应更快。

双表盘结果显示起点错开增加估计误差，与共同基线有助于视觉比较的解释一致。Cleveland 与 McGill（1984）比较的是不同图形编码，本实验比较起点对齐，因此只能在视觉比例判断任务层面讨论结果，不能把效应量直接视为原论文复现值。
