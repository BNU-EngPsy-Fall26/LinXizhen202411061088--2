# 飞行训练舱

打开 `index.html`（站点源码中位于 `dist/index.html`）。使用电脑、鼠标和键盘。无第三方运行依赖。

## W5 四表巡检

四档常态角速度为 8、16、32、64°/秒。指针在两次折返之间匀速移动，初始位置、初始方向和折返点随机。折返点在距离正常中点 25°–41° 的范围内，越限时指针用 1.4 秒平滑移向最近的红区，短暂停留后用 1.4 秒返回，再从原位置继续摆动。事件轨迹的速度上限约为 63°/秒。四根指针始终可见。鼠标位置用于近似记录正在查看的表盘，停留至少 0.1 秒计一次访问。任何表进入红区时按空格，程序自动归入当前越限。

对齐与错开各一轮，顺序随机。对齐时四表正常中点一致，错开时分别旋转 −35°、−18°、18°、35°。参照刻线、红区和指针共同旋转。每轮 16 个连续事件窗口，每窗一件事件，四块表各 4 件，起始时刻随机，越限互不重叠。每位被试两轮使用相同的角速度—位置映射。计算被试内的检出率差，并描述命中反应时。汇总只纳入本版 W5。

基于 Senders（1964），https://doi.org/10.1109/THFE.1964.231647 。原研究操纵信号带宽，本版操纵常态角速度。与原研究对照的是变化快慢和查看频率的关系。鼠标访问与眼动注视的操作定义不同，且本版将越限事件在四档间均衡安排。

## W7 双表盘

相同的 12 对角度用于起点对齐和起点错开两个条件，共 24 题，混排。起点方向覆盖四个象限方向，错开幅度为 90°，顺、逆方向均可能出现。参与者估左角为右角的百分之几。每题绝对误差以百分点计，先按参与者求各条件均值，再求错开减对齐的被试内差值。反应时作为描述性指标。

改编自 Cleveland 与 McGill（1984）的角度比例估计任务，https://doi.org/10.1080/01621459.1984.10478080 。他们比较图形编码，本任务比较双表盘的起点对齐。可以讨论两者共同的视觉比例估计任务，条件效应有各自的比较对象。

## 预测草案

- W5：指针常态角速度越高，主动查看频率越高。
- W5 改进：对齐条件的越限检出率较高。
- W7：起点对齐条件的估计绝对误差更小。

## 正式收数与提交

1. 研究者确认以上预测，将代码和 README 提交到课程 GitHub 仓库，再开始正式收数。
2. 在课程 [收数页](https://attention-lab-production.up.railway.app/hw2) 创建项目。将六位项目码补入 README，并在参与链接末尾加上 `?project=项目码`。下载密钥由研究者保管。
3. 计划邀请 12 名其他参与者，每人使用同一匿名编号完成两项。先取得知情同意。每项完成后会向课程平台上传一次。先核对课程后台中的测试项目记录，再向正式参与者发链接。上传失败时，在结果页导出 JSON 交给研究者。无项目码时也可走文件收数。
4. 从课程平台下载匿名记录。保留本地导出文件作为备份。需要在网站汇总时，可将原站导出的匿名 JSON 合并到「数据与结果」页，再导出合并结果。课程接口的 `correct` 字段在 W5 表示命中，在 W7 表示与正确比例完全相符，W7 的主要分析指标仍为绝对误差。
5. 在网页展示真实样本人数、各条件均值及被试内差值，在 README 补充结果与讨论。W5 对照原研究的采样方向，W7 对照原论文的角度比例判断，并说明当前新增条件与原论文比较条件的区别。
